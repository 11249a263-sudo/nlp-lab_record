# NLP Lab Programs

Python programs for Natural Language Processing (NLP) lab practice.

## Topics
1. Grammar-based sentence generation
2. Unigram and bigram language models
3. Regular expressions
4. Finite-state automata
5. Word stemming and lemmatization
6. Morphology and word generation
7. Part-of-speech tagging
8. Tokenization and vocabulary statistics

## Requirements
- Python 3.9+
- Optional libraries: `nltk`, `spacy`, `matplotlib`

Install dependencies:
```bash
pip install -r requirements.txt
```

Run a program:
```bash
python 01-language-models/grammar_sentence_generator.py
```

Some programs use only Python's standard library. Programs requiring downloaded NLTK data are marked in their comments.

## Note
These are organized practice files based on the topics in the NLP lab record. Check outputs on your system and update the files if your college requires a specific format.
